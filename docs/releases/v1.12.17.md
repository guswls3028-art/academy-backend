# V1.12.17 Release Notes

**Status:** Production-deployed / GO

**Release date:** 2026-08-02 KST

**Scope:** Regular/supplement lecture-session separation, compatible full-list
view, editable supplement titles, interaction hardening, and production
continuity verification

## 1. Decision

GO. Teachers can keep the previous all-sessions view or switch to a separated
view that exposes regular sessions and supplements as independent scopes. Each
scope preserves the existing attendance, score, exam, assignment, and video
entry flow. Supplement titles are now teacher-editable and remain stable after
save and reload. The release reuses the existing lecture-session model and IDs;
it adds no schema migration, data copy, or destructive conversion.

The backend candidate passed persistent development, isolated preproduction,
production migration, health-gated rolling replacement, exact-digest
verification, and manifest promotion. The frontend candidate passed isolated
preview, protected production deployment, all-tenant availability, and the
authenticated production lecture-to-session assessment flow.

## 2. Lecture Session Scope Contract

- `전체 보기` preserves the previous chronological row of every session and is
  the compatibility default. No saved preference silently changes a teacher's
  first view.
- `분리 보기` exposes `정규 수업` and `보강` filters. Regular cards contain
  ordinary numbered sessions; supplement cards contain weekend clinic or other
  supplement sessions.
- The filter is view-only state. It does not change session IDs, ordering,
  attendance, scores, assessments, or student membership, and it is reset when
  entering another lecture so a stale scope cannot hide that lecture's data.
- Creating from an empty filtered scope still supplies the selected kind, so an
  empty regular group creates a regular session and an empty supplement group
  creates a supplement session.
- The selected scope and create controls have explicit tab/button semantics and
  accessible names. The empty-state add action is announced as either
  `정규 수업 추가` or `보강 추가` instead of an ambiguous icon-only control.

## 3. Supplement Title Contract

- A supplement keeps the teacher-provided title instead of being rewritten to
  the fixed label `보강` on save.
- Updating a supplement title keeps the same session ID and kind. Existing
  attendance, assessment, score, assignment, and video relations therefore
  remain attached without migration.
- Blank or absent legacy titles continue to receive the established safe
  fallback, while a non-empty custom title is preserved exactly through API
  serialization, patch, and reload.
- Tenant filtering and existing lecture permissions remain unchanged and
  fail-closed; no cross-tenant lookup or default tenant was introduced.
