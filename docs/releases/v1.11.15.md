# V1.11.15 Release Notes

**Status:** Production-deployed / GO

**Release date:** 2026-07-26 KST

**Scope:** Academy-operation-first promotion hierarchy, four-area animated
navigator, organized feature guide, and frontend production closure

## 1. Decision

GO. The HakwonPlus promotion now explains the daily academy-management system
before presenting its four strongest areas: student video, Alimtalk, material
production, and the academy homepage. Matchup and classroom PPT production
remain prominent inside material production without defining the product's
first impression.

## 2. Delivered Behavior

- Rebuilt the main promotion around the headline that academy classes and
  operations are managed in one connected flow.
- Put lectures, students, attendance, exams, scores, assignments, questions,
  remediation, and clinic records at the center of the product explanation.
- Added a four-area hero navigator for student video, Alimtalk, material
  production, and the academy homepage. It rotates at a calm interval, pauses
  during pointer or keyboard interaction, respects reduced-motion settings,
  supports Arrow, Home, and End keyboard navigation, and provides a persistent
  pause/resume control.
- Uses prepared screenshots of actual or example product screens in the
  navigator. Visitors do not wait for source documents or PDFs to render.
- Separates the two material workflows accurately: classroom PPT production
  automatically separates PDF questions, places each prepared problem or
  concept image on its own slide, and applies black/white inversion, while
  Matchup compares the real exam with material taught before the exam.
- Reorganized the full feature guide in academy-working order: core operation,
  student video, Alimtalk, academy homepage, remediation, material tools, and
  parent consultation records.
- Added the academy homepage as a first-class area with its four available
  formats, editable introduction content, public report and post publishing,
  and links into the student and teacher service.
- Rewrote root metadata, edge-rendered metadata, navigation descriptions, and
  footer copy to use calm academy-facing Korean instead of software jargon.
- Reduced the live desktop main-page height by approximately 20 percent while
  preserving the detailed feature guide on its own page.

## 3. Compatibility and Data Safety

- No backend application code, database schema, infrastructure, API contract,
  or migration changed in this release.
- The release adds no authentication, authorization, tenant-resolution, or
  production-data mutation path.
- Existing product screenshots contain prepared example data and declare
  intrinsic dimensions to prevent layout shifts.
- Pricing and the continuing August signup price are unchanged from V1.11.14.
- Existing FAQ and grading pages retain their shared featured-card layout; the
  common style was explicitly regression-tested after the promotion rebuild.

## 4. Six-Lens Release Review

- **Backend domain:** the video-progress, Alimtalk, academy-homepage, Matchup,
  PPT, and August-price statements were checked against existing contracts.
- **Tenant isolation:** no tenant-scoped read or write boundary changed.
- **Frontend integration:** routes, metadata, prepared image assets, category
  ordering, hash links, and calls to action remain internally consistent.
- **Destructive and security:** no new external HTML injection, data write,
  form submission, or destructive production action was introduced.
- **UX and accessibility:** desktop and mobile inspection found no broken
  image or horizontal overflow. The category tabs support keyboard navigation,
  expose a persistent pause control, and respect reduced motion.
- **Regression and operations:** typecheck, lint, safety guards, production

workflow. No release-scoped Critical or High finding remains.
