# V1.11.13 Release Notes

**Status:** Production-deployed / GO

**Release date:** 2026-07-26 KST

**Scope:** Calm Korean promotion copy, product-accurate evidence, responsive
image viewing, and full frontend production closure

## 1. Decision

GO. The HakwonPlus promotion now explains the product in direct Korean that an
academy teacher or director can review without knowing software terminology.
Matchup and classroom PPT generation remain clearly separate workflows, the
evidence uses product UI with labeled example data, and every release-scoped
frontend and production gate passes.

## 2. Delivered Behavior

- Replaced software-industry slogans and sales-heavy claims with concise copy
  centered on actual academy work: class preparation, exam review, records,
  parent communication, and follow-up management.
- Described Matchup as a teacher-confirmed comparison between a real school
  exam and material the academy covered before that exam.
- Described classroom PPT generation separately: split material by question or
  concept, apply black/white inversion for a blackboard projector, export the
  PPT, and operate it with a presentation remote.
- Replaced mismatched promotional images with current product UI. Exam and
  score screenshots use explicit example students and exams and are labeled
  `제품 UI · 예시 데이터`.
- Added click-to-enlarge viewing for evidence images with keyboard close,
  focus restoration, body-scroll locking, and intrinsic image dimensions.
- Kept all promotion and Tenant 2 Matchup previews responsive without
  horizontal overflow or broken mobile images.
- Clarified the grading boundary: objective, OX, and supported numeric
  short-answer items may be auto-graded; essay answers are graded directly by
  the teacher. No essay AI score promise remains.
- Removed lifetime-price, no-increase, urgency, and unsupported savings claims.
  The page now states the VAT-inclusive monthly amount, the August application
  period, separate-cost boundaries, and that later changes follow the contract
  and Terms.
- Aligned consultation and demo privacy disclosures with the fields actually
  collected.
- Updated title, description, Open Graph image, organization metadata, and
  sitemap routes to match the calm product explanation.

## 3. Compatibility and Data Safety

- No backend application code, schema, infrastructure, or database migration
  changed in this release.
- Demo submission still uses the existing consultation endpoint. Automated
  verification intercepts that request and creates no production lead.
- Product screenshots contain prepared example data rather than live student
  data.
- Existing public Matchup PDF access remains available through an explicit
  link; the initial preview remains a prepared static JPEG.
