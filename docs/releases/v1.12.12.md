# V1.12.12 Release Notes

**Status:** Production-deployed / GO

**Release date:** 2026-07-30 KST

**Scope:** Enterprise mixed-order correctness workspace, auto-graded answer
review, spreadsheet-speed score entry, and production verification closure

## 1. Decision

GO. Teachers can now open every exam's question-level correctness sheet,
including exams that were already auto-graded. An exam with no registered
questions offers two explicit starts: register the objective answer key for OMR
auto-grading, or enter a question count and begin a direct O/X workspace.

The workspace supports objective, short-answer, and descriptive questions in
the exact original order instead of assuming grouped sections. Question type,
weight, correctness/partial score, review inclusion, answer configuration, and
student attempt state remain visible in one compact teacher workflow.

## 2. Product and Implementation

- Added the empty-exam chooser:
  - `객관식 답안 등록` opens the existing answer registration flow.
  - `문항 수로 바로 시작` creates the direct correctness workspace.
- Added an unordered question-type rail for 객관식, 단답형, and 서술형
  questions without re-sorting the teacher's exam.
- Added inline per-question weights with total-score validation and stale-write
  protection.
- Kept auto-graded objective results reviewable in the same sheet while
  preserving the recorded student answer.
- Added a dedicated `문항 구성·정답` entry for answer and type maintenance.
- Added spreadsheet-oriented operation:
  - Tab, Enter, and arrow navigation;
  - Ctrl+S save, Ctrl+Z undo, and redo;
  - multi-cell paste with O/X, Korean aliases, `.` for wrong, and `0` for
    review;
  - a pasted range is one undo action;
  - invalid pasted values reject the batch atomically.
- Added per-student attempt state and a review toggle that can include a correct
  question in wrong-note review.
- Applied a restrained teal/slate visual system, sticky identifiers, compact
  type badges, and horizontal grid behavior suitable for dense academy work.

## 3. Data and Safety Contract

- Tenant resolution remains fail-closed; no default tenant or cross-tenant
  fallback was added.
- Empty question sets now return a valid empty grading sheet instead of a
  request error.
- Question order is preserved exactly as stored.
- Objective exams that are eligible for manual review can be corrected without
  discarding the student's submitted answer.
- Locked mixed objective exams remain read-only.
- Weight changes are transactional and validate the exam total and stale
  revision before commit.
- No new Django migration was introduced. Production migration and migration
  consistency jobs completed successfully.
- No production score, answer, question, student, enrollment, or video data was
  changed during manual live verification.

## 4. Audit Findings and Fixes

- The first deployment candidate exposed a pre-existing strict-boundary import
  in the touched service. The exam dependency was moved behind the support
  adapter and the exact touched-file guard then passed.
- The first final verification read an autoscaled AI instance before SSM and
  the container were ready. Runtime digest verification now retries boundedly
  and still fails closed when the immutable digest cannot be proved.
- The permanent student canary was enrolled only in session 158, which contains
  no video. The playback smoke now checks every enrolled session and then the
  tenant public session instead of assuming the first enrolled session is
  playable.
- The playback smoke previously echoed its configured student credentials in
  workflow diagnostics. Those values are now redacted before logging, and the
  focused smoke and lint checks passed with the hardened output.
- A read-only production query proved the public session 159 contains READY,
  PUBLIC videos 284, 286, and 287. The final mechanical gate then verified the
  real student HLS chain through that public session.
