# V1.11.3 Release Notes

**Status:** Production-deployed / GO

**Release date:** 2026-07-26 KST

**Scope:** Teacher-first public promotion experience with real matchup-to-PPT
screens, honest operating guidance, explicit lead consent, and production SEO

## 1. Decision

GO. The HakwonPlus public promotion experience now speaks to Daechi teachers,
academy directors, and operators in the order they actually work: capture an
exam problem, confirm matchup candidates, build the lesson PPT, and then manage
attendance, scores, student video, parent communication, and clinics.

Generic mockups, invented operating metrics, and unsupported automation claims
were removed. The primary proof is the current product UI populated with the
Gaepo High School demonstration dataset.

## 2. Delivered Behavior

- The promotion home page leads with one clear promise and two actions:
  request a demo with the teacher's own material or inspect the real screens.
- The above-the-fold product sequence shows the actual matchup comparison and
  PPT setup screens, followed by a detailed four-step workflow.
- Field feedback that a screenshot should flow directly through matchup into a
  PPT is presented anonymously and matched to the corresponding product UI.
- Feature and parent-consultation pages explain what the teacher confirms,
  which notices can be setup-driven, and which score, result, assignment, and
  clinic messages remain manual.
- The August 2026 lifetime-guaranteed KRW 159,000 total-price policy from
  V1.11.2 is preserved across the refreshed promotion surfaces.
- Demo and contact forms require explicit privacy consent, show purpose,
  collected fields, retention, and refusal impact, and persist consent plus
  first-touch UTM attribution in the existing lead payload.
- Mobile navigation traps keyboard focus while open, closes on Escape, restores
  trigger focus, and exposes every public destination through one consistent
  sidebar.
- Every promotion route now receives route-specific title, description,
  canonical, Open Graph, Twitter, and SoftwareApplication structured metadata.
  The sitemap lists the public promotion routes; invalid promotion routes
  return 404 and trailing slashes redirect canonically.

## 3. Compatibility and Operations

- No backend runtime code, database model, migration, tenant boundary, or
  production worker changed.
- The existing public lead API contract remains compatible. Consent and
  attribution are stored in the bounded message field, with consent placed
  first so truncation cannot remove it.
- Existing promotion URLs remain valid. The deployment keeps the one-plan
  pricing contract and the latest score-entry stabilization already present on
  frontend `main`.
