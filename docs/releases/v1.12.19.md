# V1.12.19 Release Notes

**Status:** Production-deployed / GO

**Release date:** 2026-08-02 KST

**Scope:** YMath diagram-preserving question crops, answer-tail separation,
regular-order wrong-note ranges, production round-trip proof, and residue cleanup

## 1. Decision

GO. YMath-style multi-column PDFs now keep a question's trailing graph or
diagram inside the same crop while excluding the neighboring question and page
footer. Answer and solution tails are excluded from question splits without
treating an inline solution word inside an ordinary question as a section
boundary.

The production round-trip also exposed and closed an adjacent regression from
the regular/supplement session split: wrong-note range parameters represent
numbered regular sessions, so they now filter by `regular_order` and exclude
supplements instead of filtering by the mixed display `order`. The release adds
no schema migration and does not rewrite existing teacher or student results.

## 2. YMath Crop Contract

- PDF segmentation may extend a text question crop through trailing visual
  content when the visual remains inside the same column and before the next
  physical question boundary.
- The extension includes axes, labels, lines, and other diagram content without
  absorbing the adjacent column, the next question, or the page footer.
- Answer/solution section markers terminate question content only when they are
  structural section boundaries. Ordinary inline uses do not create a false
  split.
- The original source asset and every generated question crop remain tenant and
  exam scoped through the existing R2 keys and model ownership.

## 3. Regular-Order Wrong-Note Contract

- `from_session_order` and `to_session_order` refer to regular `n차시` numbering,
  not the mixed card display order.
- Range selection requires `session_type=REGULAR` and compares
  `regular_order`; supplement sessions are never selected merely because their
  display order falls inside the numeric range.
- Returned `session_order` uses the same regular-order meaning, keeping API
  filters, PDF headings, and teacher expectations aligned.
- Existing result rows, enrollments, session IDs, and supplement records are
  preserved. No backfill or compatibility rewrite is required.
