# V1.12.3 Release Notes

**Status:** Release candidate / GO pending production deployment

**Release date:** 2026-07-28 KST

**Scope:** Teacher-owned document styles and fonts, editable native HWPX
equations, and typography-preserving Hangul handoff

## 1. Decision

GO for deployment after the standard backend and frontend quality gates.

Problem Studio now carries a teacher's reusable title/body typography through
browser preview, PDF, Office-compatible DOC, HWPX, the asynchronous worker, and
the Windows Hangul companion. Chemical subscripts, superscripts, fractions, and
explicit formula markers are native editable Hangul equations rather than
visual-only Unicode in HWPX.

## 2. Implementation

- Add private per-teacher TTF/OTF uploads with 32MB/file and 30-font limits,
  fontTools structural parsing, SHA-256, cmap/glyph coverage, OS/2 embedding
  metadata, license-basis selection, and explicit rights confirmation.
- Reject TTC, WOFF/WOFF2, variable, malformed, empty, extension-mismatched, and
  over-limit fonts.
- Add reusable per-teacher title/body font, point size, line spacing, and
  question-spacing preferences.
- Resolve and revalidate tenant, teacher, asset status, SHA-256, and R2 path at
  the API, worker, and one-time Hangul handoff boundaries.
- Keep font bytes out of HWPX/result ZIP files. The one-time owner handoff
  issues short-lived font URLs only when required.
- Generate native `hp:equation` objects for Unicode sub/superscripts and
  `[[수식:...]]`, `$...$`, or `\(...\)` formula markers.
- Preserve generated section, character, paragraph, and style data during
  `InsertFile`.
- Release Windows companion v1.1.0. It verifies package/font size, SHA-256, and
  font magic, asks before current-user font installation, broadcasts the
  Windows font change, and never saves/closes/quits the user's Hangul document.
- Apply semantic sub/superscript HTML to browser/PDF/DOC output and add a
  responsive `내 문서 스타일` UI with immediate output preview.

## 4. Controlled Residuals

- Exact visual fidelity still requires licensed Hancom Hangul validation for
  the teacher's actual font/version combinations, formula layout, tables, and
  shapes.
- HWPX references font family names and intentionally does not embed licensed
  font bytes. Refusing installation or using a conflicting local family
  version can produce a fallback font.
- The current writer covers common inline equations and fractions. Complex
  multi-line matrices and source-layout reconstruction remain teacher-review
  items.
- Answer and explanation generation remains a teacher-reviewed Beta path; this
  release does not make generated answers authoritative.
