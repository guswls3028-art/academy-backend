# V1.12.4 Release Notes

**Status:** Production-deployed / GO with controlled operational warning

**Release date:** 2026-07-29 KST

**Scope:** Target-aware clinic booking, multi-enrollment-safe student linkage,
and clearer admin/student reservation operations

## 1. Decision

GO. The clinic backend and frontend are deployed, the production clinic
workflow is verified end to end, and the test data is removed.

An unresolved exam or homework result now remains the source of truth for a
student's remediation target. Booking, moving a booking, attendance, and clinic
completion do not falsely resolve that target. Resolution still requires a
passing reassessment, a passing homework review, or an explicit manual
resolution/waiver.

## 2. Implementation

- Prefer the unresolved clinic target's active enrollment when a student books
  or changes a clinic session.
- Restrict enrollment selection to the destination clinic session's target
  lectures. A targeted session with no matching enrollment fails closed rather
  than linking an unrelated course.
- Aggregate all active enrollments in the student clinic ID card and expose
  additive current-target and lecture metadata without breaking the existing
  response contract.
- Bulk-load enrollment sessions and unresolved targets to avoid an ID-card
  polling N+1 query path.
- Show the student's outstanding remediation reason, source class/session, and
  matching clinic schedule in the student app.
- Preselect the nearest eligible clinic date/session, prefer an existing active
  booking, disable dates without sessions, and keep booking state visually
  stronger than capacity state.
- Separate admin session capacity from the initially selected participants.
  A session can start with one selected student and retain nine open seats.
- Reset selection when the admin switches between remediation targets
  (`enrollment_id`) and the full student list (`student_id`), preventing mixed
  identifier domains.
- Count admin reservation summaries by student and show all associated lecture
  chips, while excluding cancelled/rejected reservations from active counts.
- Use the shared lecture-chip student-name component on clinic name surfaces.
- Align the admin/student clinic guides with the actual target lifecycle and
  booking behavior.
- Make the official E2E residue cleanup remove generic exam result, submission,
  and clinic-link rows before deleting a matched E2E exam, preventing preserved
  result snapshots from becoming orphaned test residue.

## 3. Safety and Contract Audit

- Tenant isolation: all new enrollment, target, session-assignment, and clinic
  link queries are tenant-scoped.
- Permission boundary: student booking and ID-card APIs retain the existing
  student-only access contract; admin target/session APIs retain staff access.
- Multi-enrollment integrity: the booking enrollment is selected from the
  destination session's target lectures and prefers the unresolved automatic
  clinic link.
- Lifecycle integrity: attendance/completion does not resolve the originating
  `ClinicLink`; only the domain-authorized pass or explicit resolution path
  does.
- Identifier integrity: the admin modal never submits a mixed set of
  `enrollment_id` and `student_id` values.
- Compatibility: ID-card and participant response changes are additive; no
  migration or destructive API change is required.
- Notification safety: the production real-use test used Tenant 1 and the sole
  controlled number `01031217466`.

## 5. Controlled Residuals

- The generic read-only deployment verifier can report `CONDITIONAL GO` when
  local `wrangler r2 bucket list` access is unavailable. This release does not
  change R2; both production domains, hashed assets, cache headers, and deployed
  version metadata are verified independently.
- Clinic attendance and completion intentionally do not clear a remediation
  target. Staff must record the reassessment/homework pass or use the explicit
  manual resolution path.
- A student without an active enrollment matching a targeted clinic session is
  intentionally refused rather than silently attached to another lecture.
