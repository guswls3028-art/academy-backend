# V1.11.19 Errata

**Recorded:** 2026-07-27 KST

## API default compatibility

V1.11.19 section 4 incorrectly states that clients which omit
`password_mode` receive `phone_last4`.

The shipped contract preserves the legacy API default: a client that omits
`password_mode` continues to use `fixed` with its supplied
`initial_password`. The new administrator and teacher selectors default to
`phone_last4` and explicitly submit that mode.

This is a documentation correction only. It does not change the deployed
runtime, the user-facing default, or the release decision.
