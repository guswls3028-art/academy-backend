# V1.11.25 Errata — Student Production Canary Recovery

**Recorded:** 2026-07-28 KST

This errata records the recovery of the shared student production canary that
remained deferred when v1.11.25 was sealed. It does not alter the historical
release decision or application binaries.

## Root Cause and Repair

- The failed student login was not caused by the tchul screen repair or a
  mismatched password. Tenant 1 no longer contained the configured student
  account and had no active student membership available to the canary.
- A dedicated Tenant 1 student was created through the production API with the
  controlled test recipient. Its student record is `2438`, its user record is
  `3733`, and its active tenant membership was verified.
- The repository-owned `E2E_STUDENT_USER` and `E2E_STUDENT_PASS` GitHub Actions
  secrets were aligned with that account without exposing their values.
- This is a permanent login-canary fixture. It is intentionally retained,
  excluded from one-off E2E cleanup naming, and must not be reused by
  destructive specifications.

## Production Proof

- A direct production student login returned HTTP 200 after recovery.
- The local production-canary suite passed all 4 checks: API health, public
  promotion page, administrator login, and student login.
- Frontend workflow
  [30282840977, attempt 2](https://github.com/guswls3028-art/academy-frontend/actions/runs/30282840977)
  completed successfully, including typecheck, lint, build, Hangul companion
  contract, Cloudflare deployment, tenant availability, production canaries,
  notice/QnA/clinic round trips, and the real-use session assessment.
- The deployed tchul clinic route was opened through the administrator
  navigation and rendered its input and manual-adjustment controls with no
  browser console error.
- A read-only production audit query found no new tchul
  `user_incident.frontend_exception` after the original repair deployment.

No backend runtime code, schema, migration, or deployment changed as part of
this recovery. The v1.11.25 deferred student-canary item is resolved.
