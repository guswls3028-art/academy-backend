**Scope:** Clinic score-paste assessment classification and production incident

## 1. Decision

GO for the frontend clinic-generator hotfix.

The clinic parser now treats the copied assessment headers as the classification
source of truth: only `신념 모의고사` is an exam, while textbook, supplement,
other mock-exam, and assignment headers are homework. The production
deployment and all automated production gates passed.

## 2. Root cause and repair

- The parser previously inferred assessment type primarily from cell units
  (`점` versus `%`). That made the domain rule implicit and could misclassify a
  changed external table format.
- The first reported clipboard payload also contained `-`/`-` for every
  `신념 모의고사` cell, so it carried no exam result to classify.
- Header-aware classification now takes priority, with the legacy unit inference
  retained only for headerless paste formats.
- A focused browser regression proves that `신념 모의고사` remains an exam even
  when its values use `%`, while the other copied assessment columns remain
  homework.
