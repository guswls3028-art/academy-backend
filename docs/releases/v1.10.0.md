# V1.10.0 Release Notes

**Status:** Production-deployed / GO

**Release date:** 2026-07-25 KST

**Scope:** 30/90-day infrastructure usage accounting, Academy-tagged cost
accumulation, and measured Messaging worker right-sizing

## 1. Decision

GO. The Messaging warm baseline remains one instance for account recovery and
Alimtalk latency, but its instance class is reduced from `t4g.medium` to
`t4g.small`. API, AI, Tools, RDS, Redis, and Batch classes remain unchanged
because their burst, memory, credit, or cold-start evidence does not prove a
safer reduction.

This is an infrastructure release, so the version advances from V1.9.3 to
V1.10.0. No application schema, API contract, tenant boundary, or frontend
behavior changed.

## 2. Delivered Infrastructure

- `run-cost-waste-audit.ps1` now records cumulative 30/90-day CloudWatch usage,
  current SSM host/container memory, SSOT-to-runtime capacity, Price List
  projections, account-wide Cost Explorer context, and Academy-tagged costs.
- Each audit writes both `cost-waste-audit.latest.md` and a timestamped history
  snapshot, preserving the before/after sizing evidence.
- `Project=academy` and `ManagedBy=ssot-v1` tags were applied to the Academy
  ASGs, current EC2 instances and EBS volumes, RDS, Redis, SQS/DLQs, ALB/target
  group, Batch environments/queues, ECR repositories, and DynamoDB tables.
- The Cost Explorer `Project` cost-allocation tag is Active. Tagged cost is
  prospective; charges before activation cannot be reconstructed as
  Academy-only cost.
- The Messaging SSOT, manual deployment path, Terraform mirror, operating docs,
  and current-runtime SSOT now use `t4g.small`.
- The targeted Messaging right-size path preserves the current Launch Template
  immutable image/UserData, uses the production deployment lock, maintains 100%
  minimum healthy capacity during refresh, rolls back on refresh failure, and
  verifies instance type, memory, container digest, and SQS state.

## 3. Measurement and Cost Decision

- Messaging CPU: 30-day average 0.61%, 90-day average 0.53%, 90-day peak
  57.41%; 90-day SQS sends 1,199.
- Post-change Messaging memory: 1.8 GiB total, 1.24 GiB available; container
  62.85 MiB (about 3.4%).
- Seoul Linux on-demand projection: `t4g.medium` to `t4g.small` saves
  approximately USD 15.18/month in compute. EBS, public IPv4, and tax are
  unchanged; realized savings remain pending a complete post-change billing
  interval.
- API stays `t4g.medium` after a 99.87% CPU burst.
- RDS stays `db.t4g.medium` because observed free memory reached 0.14 GiB,
  CPU credits reached zero, and connections peaked at 833 in the 90-day window.
- Redis stays `cache.t4g.small`; the single-node free-memory/credit intervals do
  not prove that a micro node has adequate operational headroom.
- AI and Tools retain scale-to-zero with their current active instance classes;
  observed burst CPU blocks a smaller AI class.

## 6. Audit Lenses and Deferred Items

- Backend domain and tenant isolation: no model, view, serializer, middleware,
  permission, or tenant-filter path changed.
- Frontend integration and UX/accessibility: no frontend repository or user
  interaction changed.
- Destructive behavior: no ECR image, Batch job definition, instance outside the
  controlled ASG refresh, database record, or storage object was deleted.
- Security: runtime verification uses the existing SSM role, emits no secret
  values, validates an immutable ECR digest, and holds the shared production
  mutation lock.
- Reliability: the refresh kept 100% minimum healthy capacity; reruns replace
  capacity only when the live fleet does not match the target class.
- An initial ECR cleanup dry-run on the stale working branch failed closed on an
  old manifest digest. The release was reapplied to current `origin/main`, whose
  manifest is ECR-valid; the final dry-run passed with zero deletable images.
- Twenty-four old ACTIVE Batch job-definition revisions remain a cleanup
  candidate. Deregistration was intentionally deferred because it provides no
  instance right-sizing benefit and was not required for this release.
- Academy-tagged realized cost and the projected USD 15.18/month saving must be
  reviewed after the next complete Cost Explorer billing interval.
