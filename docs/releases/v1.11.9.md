# V1.11.9 Release Notes

**Status:** Production-deployed / GO

**Release date:** 2026-07-26 KST

**Scope:** August lifetime-price contract hardening and public
subscription-data minimization

## 1. Decision

GO. The unrestricted single plan remains KRW 145,000 supply, KRW 14,000 VAT,
and KRW 159,000 total. Programs created from 2026-08-01 through 2026-08-31 KST
retain that price for life, including after a future list-price increase.

The follow-up audit closed two release risks. Unrelated saves can no longer
silently move an existing non-guaranteed contract to a later list price, and
the anonymous tenant bootstrap no longer exposes billing or subscription
state.

## 2. Delivered Behavior

- New programs snapshot the list price at creation.
- August 2026 programs remain force-normalized to the guaranteed KRW 145,000
  supply price on every save.
- Existing non-August contract prices remain unchanged until an explicit,
  reviewed rolling migration is run.
- Price-integrity checks and invoice creation continue to fail closed when an
  existing non-guaranteed contract no longer matches the active list price.
- The anonymous `/api/v1/core/program/` response is limited to branding,
  feature flags, UI configuration, tenant identity, and active state.
- Staff-only `/api/v1/core/subscription/` retains the full price, VAT, total,
  guarantee, and subscription contract required by the billing screen.

## 3. Compatibility and Data Safety

- No schema or data migration was required.
- No existing program, invoice, billing key, or payment row was mutated by the
  hardening change.
- The public serializer reduction is compatible with all current frontend
  bootstrap consumers; authenticated billing consumers use the dedicated
  subscription endpoint.
- A future standard-price change still requires an explicit cohort-excluding
  data migration and separate release review.
