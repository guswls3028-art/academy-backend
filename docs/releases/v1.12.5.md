# V1.12.5 Release Notes

**Status:** Production-deployed / GO

**Release date:** 2026-07-29 KST

**Scope:** Teacher-owned explanation voice profiles, rights-separated source
references, approval-driven learning, and isolated Tenant 2 fixture proof

## 1. Decision

GO. Teachers can register their own explanation style, keep publisher or
external material as content-only references, generate problems and
explanations with the selected profile, review the generated evidence and
answer checks, and explicitly approve a final edit for future style learning.

Tenant 2 remained read-only throughout the production test. A deidentified
fixture was imported only into isolated Tenant 9999, the real Bedrock
generation and review paths completed, and the AI worker returned to zero
instances after the test.

## 2. Implementation

- Add teacher-owned voice profiles with subject, style instructions, default
  selection, versioning, archival state, and tenant/owner boundaries.
- Separate style samples from content-only references:
  - teacher-authored explanations and explicitly approved output can influence
    style;
  - Matchup teacher comments can be imported as an internal style fixture;
  - publisher and other external references can influence content only.
- Require explicit material-rights confirmation. JSON `true` is the only
  accepted positive API value; string values such as `"false"` cannot bypass
  the check.
- Build a bounded, server-resolved generation snapshot. Client-supplied
  `_resolved_voice_profile` values are discarded.
- Treat source text, style examples, and content references as untrusted prompt
  data and instruct the model not to execute embedded instructions.
- Include source evidence, answer recheck text, confidence, similarity risk,
  and a mandatory teacher-review state in every generated question.
- Persist reviews append-only and learn only from an explicitly approved or
  edited final question. Repeated review submissions are idempotent.
- Scrub source text, questions, style examples, and content references from a
  completed job payload while retaining the minimal profile/review linkage.
- Restrict generation, transfer status, Hangul handoff, and review access to
  the exact requesting user in the resolved tenant.
- Fail workers closed when tenant or requesting-user contracts are absent or
  inconsistent.
- Use OpenAI only when a key is configured; otherwise use the production
  Bedrock Nova text-generation path.
- Add read-only Matchup fixture export and an import command hard-locked to
  active staff in Tenant 9999 with an `[E2E-...]` tag, privacy/rights contract,
  size/count limits, and idempotent fingerprints.
- Add the teacher UI for profile creation, source-scope selection, rights
  confirmation, profile-aware generation, quality evidence, and approval
  learning.
- Preserve each generated question's original review index across teacher
  edits, deletion, and duplication so feedback cannot attach to another
  question.

## 3. Safety and Contract Audit

- Tenant isolation: all profile, sample, review, job, and fixture queries are
  tenant-scoped; imported rows exist only in Tenant 9999.
- Owner isolation: profiles and completed jobs are scoped to the current
  teacher; cross-user status and transfer reads return not found.
- Source isolation: the Tenant 2 export is read-only and does not copy original
  files, document names, user IDs, or contact fields.
- Rights separation: external/publisher material is rejected as a style sample
  and is labeled content-reference-only.
- Privacy: phone, email, resident-registration, and common identity fields are
  masked before persistence or model context construction.
- Prompt injection: model context is resolved on the server and untrusted
  material cannot override the system contract.
- Retention: terminal job payloads retain only tenant/user/profile/count
  metadata; source and teacher sample text is removed.
- Review integrity: the original generated payload is immutable, review rows
  are append-only, and approved-output learning is explicitly linked.
- Index integrity: deleting the first generated question does not move the
  second question's review target.
- Cost: the production AI worker scaled from 0 to 3 for the proof and returned
  to desired 0 / 0 instances when the queue became idle.

  references; the product does not offer publisher-style imitation.
- The tagged Tenant 9999 profile, its 81 samples, one review, and test job
  evidence are intentionally retained as the requested isolated test
  environment. No original fixture file remains.
- Typography, personal-font embedding controls, native HWPX equations, and
  Hangul handoff remain governed by the production-deployed V1.12.3 contract.
