## 2. Hidden-Bug Closure

- Fixed a CI boundary that made Dependabot pull requests attempt secret-backed
  Cloudflare previews and credential-backed browser tests even though GitHub
  intentionally withholds those secrets from Dependabot runs.
- Dependabot pull requests now run every owned mock Playwright specification
  without credentials and proxy API traffic to an unreachable loopback port,
  so an accidental non-mocked request fails closed instead of reaching the
  production API.
- Trusted pull requests and pushes retain the full credential-backed E2E and
  Cloudflare candidate-preview gates.
- Extended the deployment-governance guard to reject a workflow that removes
  these trust and fail-closed markers.

## 8. Controlled Residuals

- `pnpm audit --prod` reports GHSA-qwww-vcr4-c8h2 in React Router 7.18.1.
  The advisory is specific to React Server Components; this production SPA has
  no RSC entry points, `@react-router/dev`, or server actions, so the affected
  execution path is absent. The upstream fix is in React Router 8.3.0 and
  requires a coordinated React/Router major migration rather than a safe patch
  bump. See the
  [GitHub advisory](https://github.com/advisories/GHSA-qwww-vcr4-c8h2) and
  [React Router changelog](https://reactrouter.com/start/start/changelog).
- Open framework, runtime, icon-library, and GitHub Actions major updates remain
  separate from this release until their compatibility and production behavior
  are proven through their owning workflows.
- No release-scoped temporary server, test account, test object, local listener,
  or uncommitted product change is intentionally retained.
