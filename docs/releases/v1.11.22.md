# V1.11.22 Release Notes

**Status:** Production-deployed / GO with customer-data setup handoff

**Release date:** 2026-07-27 KST

**Scope:** Structure-preserving cross-session exam copies, actionable Excel
template download errors, and production incident verification

## 1. Decision

GO for the application change. New exams copied from another session now keep
an independent snapshot of the source questions, weights, answer key, and
assets, so the copied exam can generate its dedicated result-import workbook.
When a workbook still cannot be generated, the frontend now displays the
backend's actionable reason instead of the generic download-failure toast.

The reported Ymath exam `604` was not changed automatically. It has no sheet,
questions, or answer key, and no matching safe source exam exists in the
tenant. Its actual question count and weights must be confirmed before that
customer record can be configured.

## 2. Delivered Behavior

- The cross-session copy request now sends `source_exam_id`.
- Regular-exam creation accepts an active regular source only within the
  request tenant.
- The effective source structure is copied into the target as independent
  rows; later edits cannot mutate the source exam or sibling copies.
- A request cannot combine `source_exam_id` with `template_exam_id`.
- Cross-tenant and invalid sources fail closed before a target exam is
  persisted.
- Blob error responses from the workbook endpoint are decoded, so a
  structure-less exam now shows `시험 문항을 먼저 등록해 주세요.` rather than
  only `엑셀 양식을 내려받지 못했습니다.`

## 6. Audit Closure

The release-scoped source was reviewed through backend-domain, tenant
isolation, frontend integration, destructive-edge, UX/accessibility, and
security lenses.

- Domain: copied questions, weights, answer keys, explanations, and assets use
  the established independent snapshot service.
- Tenant isolation: source lookup is tenant-scoped, the effective structure
  owner is checked again, and a cross-tenant regression test fails closed.
- Frontend integration: the existing copy flow adds one source identifier, and
  existing error presentation receives the decoded backend detail.
- Edge cases: malformed IDs, inactive/non-regular sources, conflicting source
  modes, empty structures, and cleanup were reviewed; no delete behavior was
  added.
- UX/accessibility: no layout or interaction contract changed; the visible
  failure text is now actionable on the existing feedback surface.
- Security: permissions are unchanged, IDs are integer-validated, no
  cross-tenant fallback exists, and no spreadsheet execution surface was
  introduced.

Critical findings: 0. High findings: 0. No code or runtime blocker remains.
