# V1.11.24 Release Notes

**Status:** Production-deployed / GO with licensed Hangul reopen pending

**Release date:** 2026-07-27 KST

**Scope:** Problem Studio HWPX damaged-file repair, runtime dependency closure,
and production package validation

## 1. Decision

GO for production HWPX generation. The `03_자체양식_문제검수본.hwpx`
artifact is no longer assembled from a partial hand-written ZIP/XML package.
It now starts from an editor-compatible HWPX skeleton, preserves the review
text in both the document section and `Preview/PrvText.txt`, and passes the
repository and production package validation gates.

The remaining device-owned check is opening the new production artifact in a
licensed Hancom Hangul editor. The current verification machine does not have
that application, so the existing licensed-editor UAT item remains
`needs-manual-validation`.

## 2. Root Cause and Repair

- The legacy writer emitted a plausible ZIP but omitted or malformed strict
  package details including the header section count, required namespaces, the
  application-settings root, and the header spine reference.
- Existing tests checked filenames and ZIP ordering but did not reopen or
  schema-validate the generated package.
- The writer now uses `python-hwpx==4.2.0` and its editor-compatible document
  skeleton instead of maintaining a second partial HWPX implementation.
- The title and review paragraphs are written through the document object
  model, while the normalized text preview is synchronized explicitly.
- The API, shared smoke/runtime environment, AI CPU worker, and deterministic
  tools worker all pin the same writer dependency.
- Regression coverage now asserts ZIP ordering/compression, header,
  settings, content references, preview/section text, package reopen, and
  schema validity.

## 3. Compatibility and Boundaries

- The public route, request payload, result ZIP layout, and HWPX filename are
  unchanged.
- No frontend, database migration, tenant query, authorization, billing, or
  destructive-data behavior changed.
- The synchronous API, AI transcription worker, and deterministic transfer
  worker use the same package builder.
- The output remains a text-focused teacher review workbook. Exact native HWP
  layout reproduction, rich formulas, tables, and shapes are not newly
  promised by this patch.
