## 요청사항

- 표시명은 정성원연구소이며 대표원장은 정성원이다. 연락처는 운영 계정 생성 시 사용자가 전달한 값을 적용한다.
- 표준 기능 전체를 제공하고 아래 항목을 집중 검증한다. 역할별 접근 권한은 표준 제품 정책을 따른다.
- 강의 영상은 자막 없이 운영한다. 강사·학생 영상 동선에서 업로드와 재생을 확인한다.
- 원장은 후속 전달된 정식 계정으로 등록한다. 기존 원장 체험 계정 계획은 취소했다. 학생 체험 계정은 기존 요청대로 준비한다. 대표자는 첫 로그인에서 비밀번호 변경 권유를 미루고 업무를 시작할 수 있다. 계정 준비는 `--require-owner`로 확인한다. 대표자의 실제 변경·재로그인과 격리 확인은 G8에, `--require-owner-handoff`를 포함한 감사 결과는 G9에 기록한다.
- 강사 적응을 위한 이용기간은 2027-01-01 KST까지다. 운영에서 전체 기능 플랜과 해당 만료일을 확인했다.
- 알림톡은 공용 채널의 승인된 템플릿을 사용한다. 운영 설정 및 라우팅 확인과 실제 수신 검증의 결과를 각각 기록한다. [메시징 정책](../../ssot/messaging-policy.md)
- 사용자 본인 번호를 학생 체험 계정의 보호자 연락처와 알림톡 1건의 테스트 수신처로 지정했다. 번호는 운영 입력에만 사용한다.
- 고객 로고의 흰색 워드마크와 네이비 배색을 로그인·관리자 콘솔·학생앱에 반영한다. 로그인 진입 애니메이션은 한 번만 재생하고 동작 줄이기 설정을 따른다. 데스크톱과 390px, 역할별 밝은 화면과 어두운 화면에서 점검한다.
