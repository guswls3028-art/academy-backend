**확인일** 2026-11-19 KST

**상태** 새 도메인 등록·공개 DNS 위임 확인, 서비스 배포 대기

## 요청사항

- 표시명은 정성원연구소이며 대표원장은 정성원이다. 연락처는 운영 계정 생성 시 사용자가 전달한 값을 적용한다.
- 표준 기능 전체를 제공하고 아래 항목을 집중 검증한다. 역할별 접근 권한은 표준 제품 정책을 따른다.
- 강의 영상은 자막 없이 운영한다. 강사·학생 영상 동선에서 업로드와 재생을 확인한다.
- 원장은 후속 전달된 정식 계정으로 등록한다. 기존 원장 체험 계정 계획은 취소했다. 학생 체험 계정은 기존 요청대로 준비한다. 대표 계정의 제품상 최초 비밀번호 변경 절차를 적용한다.
- 강사 적응을 위한 체험 이용기간은 2027-01-01 KST까지다. 운영 반영 후 실제 이용 가능 기간을 확인한다.
- 알림톡은 공용 채널의 승인된 템플릿을 사용한다. 운영 설정 및 라우팅 확인과 실제 수신 검증의 결과를 각각 기록한다. [메시징 정책](../../ssot/messaging-policy.md)
- 사용자 본인 번호를 학생 체험 계정의 보호자 연락처와 알림톡 1건의 테스트 수신처로 지정했다. 번호는 운영 입력에만 사용한다.
- 고객 로고의 흰색 워드마크와 네이비 배색을 로그인·관리자 콘솔·학생앱에 반영한다. 로그인 진입 애니메이션은 한 번만 재생하고 동작 줄이기 설정을 따른다. 데스크톱과 390px, 역할별 밝은 화면과 어두운 화면에서 점검한다.

## 배포 전 점검 기록

- 2026-11-19 KST에 [프런트 빌드 44515103544](https://github.com/guswls3028-art/academy-frontend/actions/runs/44515103544)의 산출물을 로컬에서 열고 합성 API 응답으로 확인했다. 로그인은 1366px·390px·320px에서 입력·오류 복구·비밀번호 찾기를 점검했다. 약관과 개인정보 처리방침은 해당 링크를 열 때 로드되며 새로고침과 로그인 복귀를 확인했다.
- 같은 산출물에서 원장·학생·학부모 홈과 원장·학생의 성적·클리닉·질문·과제/제출함을 1366px·390px로 확인했다. 총 22개 화면에서 테넌트 로고가 표시됐고 가로 넘침이나 브라우저 실행 오류가 없었다.
- 메시징 워커 실패 처리, 알림톡 승인 경계, AI 테넌트 분리, 도구·Excel 작업 라우팅의 로컬 회귀 검사 73개가 통과했고 1개가 건너뛰어졌다. 운영 로그인, 실제 작업 처리 결과, 공급사 전달과 단말 수신은 배포 뒤 위 표에 각각 기록한다.

## 도메인과 진행 상태

- 확정 도메인은 `정성원영어.com`이며 DNS 표기는 `xn--oj4bo6fugp3an0c.com`이다. 2026-11-19 KST에 사용자가 기존 도메인을 환불하고 이 도메인으로 등록하기로 했다. 테넌트의 표시명, 기능과 체험 조건을 새 주소에 적용한다.
- Cloudflare가 발급한 1차는 `barbara.ns.cloudflare.com`, 2차는 `thaddeus.ns.cloudflare.com`이다. 2026-11-19 KST에 `.com` 등록부와 Google·Cloudflare 공개 DNS에서 이 두 NS로 위임을 확인했으며, Cloudflare 영역의 활성화 검사를 요청했다. Pages와 HTTPS 연결은 정식 배포 및 DB 준비 이후 진행한다.
- 확정 테넌트 코드는 `jeongseongwon-lab`이다. 운영 DB 목록에서 ID `12`의 공석을 확인했으며, 실제 등록 전에 다시 확인한다. 고객이 제공한 정성원영어 로고와 네이비·화이트 팔레트를 적용한다.
- 운영 DB 등록, 계정 생성, 기능 실측은 대기 중이다. 후속 증거는 [커스텀 도메인 온보딩](custom-domain.md)의 해당 단계와 함께 이 문서에 갱신한다.
