테넌트마다 이 목록에서 연결하는 운영 문서 한 곳에 고객 요청과 예외 설정을 기록한다.
요청·설정·제약·검증 결과가 바뀔 때마다 해당 테넌트 문서를 갱신하고, 확인일과 근거,
남은 작업 및 재개 조건을 기록한다. 신규 테넌트 문서는 [온보딩 실행표](onboarding-run-sheet.md)를
참고한다. 로그인 ID·비밀번호, 개인 연락처, 고객 원본 자료는 Git 문서에 넣지 않는다.
