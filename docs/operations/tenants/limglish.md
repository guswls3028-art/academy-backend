# 임근혁 영어 학원별 운영 정책

대상은 운영 테넌트 코드 `limglish`인 임근혁 영어(`limglish.kr`)입니다.
공통 기능에서 이 학원에만 다르게 적용하는 동작과 그 근거를 이 문서에 모읍니다.

## 차시 성적 탭의 영상 학생 수업결과 알림톡

교사가 차시 **성적** 탭에서 **수업결과 알림톡 발송**을 열면, 선택한 영상 출결
(`ONLINE`) 학생도 일반 성적 알림 대상에 포함됩니다. 해당 학생에게 배정된
과제를 교사가 `/`로 입력해 **미제출**(`NOT_SUBMITTED`)로 확정하면, 알림톡의
과제 결과 변수에 **영상보강**이 표시됩니다. 과제 제출 후 채점하면 다음 알림톡에
기록된 점수나 완료 판정이 표시됩니다.

**영상보강**은 학생별 본문을 조립할 때 쓰는 표시입니다. 출결·시험·과제 상태나
기존 성적을 변경하거나 새로 저장하지 않습니다. 기존 시험 표기, 과제 배정,
수신자 확인, 알림톡 미리보기와 발송 절차는 공통 정책을 따릅니다. 다른 학원은
기존 성적 알림 대상과 과제 결과 표기를 사용합니다.

테넌트별 적용 범위와 화면 진입점은 [차시 성적 화면](https://github.com/guswls3028-art/academy-frontend/blob/main/src/app_admin/domains/lectures/pages/scores/SessionScoresEntryPage.tsx)이 소유합니다.
학생별 과제 결과와 안내문 변수 표기는 [공통 성적 변수 포매터](https://github.com/guswls3028-art/academy-frontend/blob/main/src/shared/scoring/scoreReport.ts)가 소유합니다.
발송 권한, 수신자와 승인 템플릿 경계는 [메시징 도메인](../../domain/messaging.md)을 따릅니다.

검증할 때는 운영 학원 대신 격리 개발 환경에서 합성 학생과 차시를 사용합니다.
영상 학생의 확정 미제출 과제, 점수형과 완료형의 저장된 결과, 시험 결과를
같은 미리보기에서 확인합니다. 다른 학원과 현장 학생을 대조하고, 표시가
바뀐 뒤에도 출결과 성적 데이터가 그대로인지 확인합니다.

## 학원별 요청 기록 방법

새 요청이 확정되면 이 문서에 적용 학원·화면·역할, 발동 조건, 화면과 알림톡에
보이는 결과, 권한·데이터 경계, 실패 시 복구, 검증 방법과 코드·공통 정책 링크를
추가합니다. 새 요청이 기존 예외를 대체하면 적용 범위와 기존 데이터의 처리
방식을 함께 갱신합니다. 교사 대화 원문과 학생·학부모 개인정보는 남기지 않습니다.
