# 프로그램 표시·기능 설정

`GET/PATCH /api/v1/core/program/`는 요청 학원의 표시 이름·브랜드·로그인 화면과
기능 설정을 제공한다. 공개 GET은 학원 문맥이 필요하며 읽기 중 Program을 만들지
않는다. 누락된 Program은 404로 표시하고 다른 학원 설정으로 대체하지 않는다.

PATCH는 현재 학원의 활성 교직원에게 허용한다. 요금제·활성 여부·기능 플래그는
기존 owner/superuser 검증을 추가로 통과해야 한다. 구독 만료·해지·가격·청구 필드는
이 API의 수정 대상이 아니며 billing 서비스가 소유한다.

부분 저장은 Program 행을 잠그고 최신 값에 요청 필드만 적용한다. 다른 담당자의
브랜드 변경이나 billing의 해지 예약을 오래된 조회값으로 덮어쓰지 않는다. 응답도
실제 저장한 최신 행에서 만들며 다시 GET한 결과와 일치한다. `feature_flags`와
`ui_config`는 JSON 객체만 허용한다. 배열·문자열 설정 및 객체가 아닌 요청 본문은
400으로 거부하고 기존 설정을 보존한다. 올바른 객체로 정정 후 재시도할 수 있다.

JSON 객체 자체는 해당 필드의 교체 계약을 유지한다. 같은 JSON 필드를 동시에
편집하는 경우의 버전 충돌 표시나 키별 병합은 이 수정에 포함되지 않는다.
과거 저장 데이터를 자동 변경하거나 구독 정책·운영 HOLD를 해제하지 않는다.
화면 상호작용은 frontend `docs/USER-GUIDE-ADMIN.md`와 설정 화면이 소유한다.

검증: `apps/core/tests/test_program_update_integrity.py`에서 오래된 표시 설정 수정
뒤 해지 예약·다른 설정 보존, 응답·reload 일치, 잘못된 JSON의 무변경 및 정상 재시도를
확인한다. 관련 구독 전이와 테넌트·역할 경계는 billing/core 회귀로 함께 확인한다.
