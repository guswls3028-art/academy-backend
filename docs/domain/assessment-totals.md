# 차시별 선택 평가 총점

교직원은 차시 성적표에서 시험과 점수형 과제의 합산 대상을 각각 정한다.
`시험1 → 시험2 → 총점 → 시험3` 구성은 시험1·2만 합산한다. 통과형 과제
(`COMPLETION`)는 O/X 판정이며 점수형 과제 총점에 포함되지 않는다.
기존 과제의 채점 방식·원점수·커트라인·교사 완료 판정은 그대로 보존한다.

## 저장과 권한

`Session.score_totals`에는 version, exam_ids, homework_ids와 차시별
exam_order/homework_order를 저장한다. 공유 시험의 전역 순서는 변경하지 않는다.
설정이 없는 기존 차시는 현재 모든 시험과 점수형 과제를 합산한다. 저장된 빈
목록은 합산 대상 없음이다. 설정 이후 새로 만든 평가는 자동 포함하지 않으며,
제거된 평가 ID는 조회 시 현재 목록과 교집합으로 제외한다.

`GET/PUT /results/admin/sessions/{session_id}/total-config/`는 인증된 해당
tenant 교직원만 허용한다. PUT의 expected_version으로 행을 잠근 뒤 충돌을
검사한다. exam_order/homework_order를 함께 보내면 차시별 평가 순서 저장과
선택 저장을 한 transaction에서 처리한다. 다른 차시 ID, 중복 ID, 통과형
과제 포함, 불완전한 순서는 400이며 전체 변경을 취소한다. 동시 수정은 409로
기존 값을 보존한다. UI는 최신 설정을 확인한 뒤 다시 편집할 수 있다.

## 계산과 후속 소비자

`assessment_totals.py`가 관리자 성적표와 학생·학부모 성적 요약의 계산을
공유한다. 학생에게 배정된 선택 평가만 분모에 포함한다. 결석으로 학습 대상에서
제외된 미응시 시험 중 제출·응시·정정 기록도 없는 항목과 배정이 해제된
과거 과제는 총점에 더하지 않으며 성적 이력은 보존한다. 결석이어도 기록이
있는 미채점 시험은 관리자와 같이 분모에 남아 집계 중으로 표시한다.
결과가 하나도 없는 시험 차시도 권한 있는 활성 수강의 출결 우선 명단과
차시별 시험 배정 규칙으로 찾아 집계 중을 표시한다. 공유 시험의 결석 판정은
표시용 중복 제거 전의 수강별 원본을 사용한다.
학생·학부모 합계는 공개 허용된 수강별 1차 점수를 표시용 시험 이력의 중복
제거 직전 원본에서 받는다. 공유 시험을 여러 강의에서 응시해도 각 수강의
점수를 유지하며, 시험 이력 화면의 exam_id별 중복 제거 정책은 바꾸지 않는다. 만점은 현재 평가
설정을 따른다. 미입력·미제출·주관식 채점 중·잠정 점수를 0점으로 확정하지
않으며 scored_count/selected_count와 complete를 함께 보낸다. 실제 0점은
입력된 점수로 센다. 대상이 없으면 complete=false, score=null이다.

성적표 각 행의 exam_total/homework_total, 요약 API의 session_totals는
원점수를 변경하지 않는 파생 값이다. 재시험 성적을 1차 총점에 섞지 않는다.
메시지 총점 블록은 미완성일 때 집계 중을 표시하며 익명 성적 분포 PDF는
확정된 총점만 집계한다. 기존 클리닉·진도·개별 통과 판정은 선택 변경의
영향을 받지 않는다. 출결 메모 및 학부모 전용 코멘트와도 별개다.

## 호환과 검증

lectures 0009는 nullable JSON 열에 빈 JSON 앱 기본값을 추가하는 expand
migration이다. 이전 서버가 열 없이 INSERT해 저장한 NULL도 미설정으로 읽는다. 기존
클라이언트 요청과 점수 행은 보존되며 backend를 먼저 배포한다. frontend
화면 계약은 [ASSESSMENT-TOTALS.md](https://github.com/guswls3028-art/academy-frontend/blob/main/docs/ASSESSMENT-TOTALS.md)가 소유한다.

회귀는 `test_assessment_totals.py`에서 선택·미입력·0점·미배정·통과형 제외,
저장/reload/충돌, tenant·역할 차단, 순서 저장의 원자성을 검증한다. 개발
실사용에서는 이동→저장→reload→학부모 화면·메시지와 desktop/390px를 확인한다.

학생·학부모 요약의 명단·평가·시험 배정은 요청 범위의 차시를 묶어서 읽는다.
출결 우선 여부와 명시적 시험 배정 유무는 학생 한 명으로 제한하기 전에
학급/시험 전체에서 판단한다. `test_student_totals_query_budget.py`는 1개에서
12개 차시로 늘어도 조회 수가 증가하지 않는지, 타 tenant·비활성 시험을
제외하고 미응시 합계와 위 명단/배정 규칙을 유지하는지 검증한다.
