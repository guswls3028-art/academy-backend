# 직원·근태·정산 도메인

학원 대표와 권한을 위임받은 강사·조교가 직원을 등록하고 근태·직원 선결제 환급·월마감을 관리하는 현재 운영 정책이다. 이 기능은 근태와 월별 내부 정산을 보조하며, 세무·노무 급여 엔진이나 법정 임금명세서를 대신하지 않는다.

## 권한

| 행위 | 대표·admin | `is_manager=true` 강사·조교 | 일반 강사·조교 |
|------|------------|-----------------------------|----------------|
| 직원·시급·비용·정산 조회/관리 | 가능 | 가능 | 불가 |
| 본인 출퇴근·휴게 | 가능 | 가능 | 가능 |
| 대표 비밀번호 초기화 | 불가 | 불가 | 불가 |
| admin 비밀번호 초기화 | 대표만 가능 | 불가 | 불가 |
| 급여 조정액 입력 | 가능 | 가능 | 불가 |

- 권한의 정본은 현재 테넌트의 활성 `TenantMembership`이다. `User.tenant` 포인터만으로 권한을 부여하지 않는다.
- 일반 직원의 출근은 본인에게 배정된 활성 `StaffWorkType`만 허용한다.
- 배정 근무유형이 여러 개면 출근 전에 유형과 단가를 직접 선택한다.
- 직원 명부 읽기는 활성 테넌트 직원에게 허용할 수 있지만, 강사 명부 쓰기는 급여관리 권한이 있어야 한다.
- 관리자 권한과 비밀번호 초기화는 운영 감사 로그를 남긴다.

## 직원 생명주기

1. 등록 시 역할은 강사 또는 조교다. 계정을 만들면 초기 비밀번호는 4자 이상이며 다음 로그인에서 변경해야 한다.
2. 재직 중 이름·전화·역할 변경은 Staff, 연결 User, TenantMembership, 강사 명부를 한 트랜잭션에서 맞춘다.
3. 퇴사 처리는 `is_active=false`로 전환한다. 진행 중 근무가 있으면 거부하며, 로그인 멤버십과 관리자 권한을 중지한다.
4. 근무·비용·월마감·급여 스냅샷은 퇴사 후에도 보존한다.
5. 영구 삭제는 오등록 정리용이다. 위 이력이 한 건이라도 있으면 거부한다.
6. 재입사는 역할을 명시해 재활성화한다.

## 근태 불변 규칙

- 직원별 미종료 근무는 최대 한 건이다.
- 시작과 종료 시각은 같을 수 없다. 종료가 시작보다 이르면 다음 날 종료로 계산한다.
- 휴게·식사시간 합계는 전체 근무시간보다 짧아야 한다.
- 휴게 중 generic PATCH로 근무를 종료할 수 없다. 표준 퇴근 액션이 휴게를 정산하고 종료한다.
- 일반 직원은 퇴근 요청으로 `adjustment_amount`를 입력할 수 없다.
- 월마감 이후 해당 직원·월의 근무와 비용은 생성·수정·삭제할 수 없다.
- 적용 시급은 출근 시점에 `resolved_hourly_wage`로 고정한다. 이후 단가 변경이나 재계산이 이미 시작된 근무에 소급 적용되지 않는다.

## 직원 선결제 환급과 월마감

- 이 항목은 직원이 개인 비용으로 먼저 결제한 환급 대상만 등록한다. 학원 법인카드·계좌로 직접 지출한 비용은 넣지 않는다.
- 새 환급은 요청 값과 관계없이 `PENDING`으로 생성한다.
- 승인·반려는 관리자 전용 상태 전이다.
- 승인·반려된 환급은 감사 이력 보존을 위해 수정·삭제할 수 없다. 정정은 새 대기 항목으로 등록한다.
- 월마감은 append-only이며 근태·환급 정산 스냅샷을 함께 생성한다.
- `MONTHLY` 직원은 자동 월마감을 거부한다. 근로계약·수당·공제를 확인해 별도로 정산한다.
- 마감 상태 조회가 실패하거나 진행 중이면 클라이언트는 쓰기를 허용하지 않는다.
- 정산 엑셀은 해당 월에 근무·환급 기록이 있는 직원 전원의 스냅샷이 있어야 생성한다. 현재 재직 여부를 과거 월에 소급하지 않는다.
- 스냅샷 ID 집합과 revision을 워커 payload에 고정하며, 워커는 정확히 같은 집합만 조회한다.

## 금액 표시 계약

현재 자동 계산:

```text
근무기록 금액 = 근무시간 × 적용 시급 + 관리자 조정액
정산 합계(공제 전) = 근무기록 금액 + 승인 선결제 환급
```

- 화면과 PDF는 `정산 합계(공제 전)`을 표시하며 PDF 제목은 `근태·경비 정산 참고서`다.
- 세금 3.3%, 근로소득세, 4대보험, 기타 공제를 자동 추정하지 않는다.
- 실제 지급액은 계약 형태와 공제 내역을 확인한 뒤 외부 급여/세무 절차에서 확정한다.
- 연장·야간·휴일수당을 자동 계산하지 않는다. 적용 요건과 계산은 별도 확인한다.
- `MONTHLY`에는 기본급·일할·연장·휴일·공제 정책이 아직 없다. 신규 선택과 자동 월마감을 막고, 기존 값은 `월급(수동 확인)`으로 표시한다.

## 목록·내보내기 계약

- 직원 도메인 목록은 `page_size`를 지원하며 최대 500건으로 제한한다.
- 관리 화면은 월별 근태·환급과 직원 명부를 `page_size=500`으로 요청하고 `results`를 소비한다.
- 급여 스냅샷 조회는 `staff`, `year`, `month` 서버 필터를 적용한다.
- 신규 스냅샷은 월마감 당시 직원명을 복제해 이후 개명·오타 수정이 과거 정산서를 바꾸지 않게 한다. additive migration 이전 행은 현재 이름으로 안전하게 fallback한다.
- PDF는 한글 폰트를 등록해 이름과 한글 항목명이 깨지지 않게 한다.

## 개인정보 최소화

직원 관리에는 이름, 연락처, 역할, 재직 상태, 계정, 업무별 단가와 정산 이력만 저장한다. 주민등록번호 같은 고위험 정보는 별도의 법적 근거·암호화·접근통제·파기 정책 없이 추가하지 않는다.
