# 클리닉 대상과 강의 종료 상태

## 목적과 화면

관리자·조교의 **클리닉 → 전체 미통과**는 현재 보강 판단이 필요한 평가 항목을
보여 준다. 학생의 **클리닉 → 예약하기** 달력은 이미 개설된 미래 클리닉 일정을
보여 준다. 두 목록은 서로 다른 사실이다. 현재 강의의 차시라도 시험·과제 미통과
또는 직원이 확정한 미응시 근거가 없으면 미통과 목록에 자동으로 만들지 않는다.
반대로 미통과 항목이 있어도 대상 학년·학교 유형·강의에 맞는 미래 일정이 아직
개설되지 않았으면 예약 달력은 비어 있을 수 있다.

## 현재 대상의 경계

`GET /api/v1/results/admin/clinic-targets/`는 인증된 관리자·교사와 확정된 tenant만
허용한다. 현재 목록의 자동 `ClinicLink`는 미해결 상태, 실재하는 정규 시험·과제와
학생별 배정, 활성 수강·활성 강의, 같은 강의의 차시, 미완료
`SessionProgress`를 모두 만족해야 한다. 명시적 `NOT_SUBMITTED` 시험은
`ClinicLink`가 없어도 판정 대기 항목으로 투영하지만 같은 활성·완료 경계를
적용한다. 점수가 단순히 비어 있다는 이유만으로 결시를 추정하지 않는다.

강의 **종료**는 `Lecture.is_active=false`다. 종료 강의의 미해결 항목은 현재
작업대와 학생 패스카드·이름 강조에서 빠지고, 현재 예약 대상 강의로도 사용하지
않는다. 종료는 수강·평가·클리닉 링크·예약 기록을 삭제하거나 자동 면제하지
않는다. 강의를 복원하면 아직 미해결이고 원본·배정·차시 상태가 유효한 항목만
다시 현재 대상으로 보인다. `include_resolved=true`는 해소 이력을 추가로 보여
주지만 종료·완료된 미해결 항목을 현재 작업으로 되살리지 않는다.

기존 예약 참가자 API는 당시의 `lecture_title` 등 강의 이력을 보존하고,
`lecture_current`에 수강과 강의가 모두 활성인지 별도로 내려준다. 직원의
참가자 명단에서는 이 값이 거짓이면 학생 이름 옆의 현재 강의 딱지를 숨긴다.
강의 복원 시 참가자 이력을 새로 만들지 않고 표시 상태만 다시 활성화한다.

## 예약과 실패 복구

`GET /api/v1/clinic/sessions/`의 학생 조회는 미래 일정 중 학년·학교 유형 및
현재 활성 수강 강의의 대상 조건에 맞는 세션만 반환한다. 활성 수강 강의가 없으면
예약 가능한 일정이 없다. 교직원의 일정 조회와 기존 참가자 이력은 유지한다.
학생 예약은 조회와 같은 활성 수강·대상 강의 조건을 서버에서 다시 검사하며,
종료 강의만 가진 학생의 새 예약은 거절한다. 이미 저장된 예약을 이 상태 변경만으로
취소하거나 옮기지 않는다.

직원이 명시적 미응시 항목을 면제할 때는 최신 결과, 정확한 시험·차시·수강
배정, 활성 강의, 미완료 차시를 다시 확인한다. 상태가 그 사이 바뀌면 `404/409`
로 실패하고 링크를 새로 쓰지 않는다. 화면은 재조회 후 현재 항목을 선택하게 한다.
tenant가 없거나 역할이 맞지 않으면 조회·쓰기 모두 거부한다.

현재 강의의 기대 단원이 누락되면 먼저 수강 상태, 학생의 차시 배정,
시험·과제의 차시 연결, 최신 결과·미응시 표시, 자동 링크의 생성·해소 상태를
확인한다. 해당 평가 근거가 없는 단원은 수업 계획과 구분해 다루며, 목록 조회로
점수나 링크를 만들지 않는다.

클리닉 달력에 강의별 일정이 없으면 먼저 교직원이 해당 날짜·대상 강의의
클리닉 세션을 실제로 열었는지 확인한다. 학년·학교 유형 제한 세션은 학생
프로필의 명시된 값과 대조한다. 강의 제목에서 학년을 추정해 프로필이나
예약 자격을 자동 변경하지 않으며, 불일치는 학생 관리에서 확인 후 수정한다.

## 검증

- `apps/domains/results/tests/test_admin_clinic_targets_contract.py`: 종료 강의 제외,
  해소 이력 보존, 복원, 현재 다른 강의의 대상 유지, tenant·권한.
- `apps/domains/results/tests/test_admin_clinic_missing_exam_waiver.py`: 완료 차시,
  종료 강의, 비활성 수강의 미응시 투영·면제 차단.
- `apps/domains/clinic/tests.py`의 `StudentClinicPermissionAPITest`: 종료 강의의
  달력·예약 차단, 현재 중3 강의 일정·예약 유지, 일반 일정의 활성 수강 조건.

예약 방식·정원·동시성 계약은 [클리닉 예약 정책](clinic-booking.md)이 소유한다.
