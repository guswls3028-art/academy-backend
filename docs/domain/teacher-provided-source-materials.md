팔레트, 도넛+4칸 표, 슬라이드 순서와 레이아웃은 복제하지 않는다. 제품 산출물은
`EXAM SPECTRUM` 디자인 시스템을 사용한다.

### tchul 실제 분석 대상

`tchul 작업용 문제/`의 아래 두 8쪽 PDF는 서로 다른 시험으로 각각 한 리포트로
분석한다.

- `2026 언남고 1학기 중간고사 생명과학.pdf`
- `2026 언남고 1학기 중간고사 생명과학 (1).pdf`
- `완성된 리포트 도구로 위 2파일을 분석해서 tchul 홈페이지에 홍보용도로 올릴것.txt`

중복처럼 보이는 파일명만으로 시험 구분을 추측하지 않는다. 페이지 내용과
교사가 확인한 metadata로 중간/기말을 명시하고, 분석 검수본·PDF·PPTX를 확인한
뒤 공개 mutation을 별도로 실행한다.

### 조판·문체

- A4, 대체로 2단, 대표 단 간격 8mm와 점선 중앙선.
- 본문 한겨레결체 9pt. 문서 자동 감지가 우선이며 교사 수동 프리셋은
  자평 96%, 자간 -4%, 줄간격 150%를 지원한다. 실제 문서에는 150~160%와
  다른 자평·자간이 섞일 수 있다.
- 선지 해설은 정답 선지의 근거를 먼저 자세하고 친절하게 설명한 뒤 `[오답]`
  아래에 틀린 선지의 이유를 배치한다.
- HWPX `section*.xml`과 미주를 사용해 문제·정답·해설의 연결을 보존한다.
  그림·수식은 캡처로 평탄화하지 않고 가능한 한 편집 가능하게 유지한다.
- 별도 원본 이관 흐름은 PDF 문제·해설을 HWP로 타이핑하면서 교사 스타일과
  문항별 미주를 함께 보존해야 한다. 단순 본문 OCR이나 화면 캡처 결과는
  완성본이 아니다.
- `문제작성_철선생님_골든검수_20260729/GOLDEN_QUALITY_REPORT.md`가 현재
  골든 검수 수치와 비공개 등급의 정본이다.

### 보안

교사가 명시한 비공개 내부 테스트 전용 자료다. 원본이나 격리 사본을 운영 서버,
웹, 외부 AI로 보내지 않는다. 운영 검증에는 합성 자료만 사용한다. 문체 적용은
업로더의 작성·사용 권리 확인이 있을 때 해당 작업 안에서만 허용하며 다른
테넌트로 학습·공유하지 않는다. 개인 글꼴도 테넌트·업로더 범위로 격리한다.

### 제품 요구

- 한글 A4 한 페이지를 위아래 두 구역으로 나누고 한 문제씩 배치하며 원 시험지
  양식을 정갈하게 유지한다.
- 시험뿐 아니라 워크북 과제도 문항 분리·정오 기록·오답노트 대상이 된다.
- 한 학생의 여러 시험과 여러 워크북에서 선택한 오답을 한 권으로 합칠 수 있어야
  한다.
- 문제와 해설의 연결은 이미지 캡처 추측보다 HWP 미주 번호·ParaText·EqEdit
  원문 구조를 우선한다. 범위가 불규칙한 picture control은 자동 정본이 아니라
  교사 직접 확인용 attachment로 보존한다.
- 제공 archive와 글꼴은 내부 참고·검수 범위이며 테넌트 밖으로 공유하지 않는다.

## 공통 사용 원칙

1. 루트 자료는 immutable reference다. 가공본과 렌더 QA는 `_artifacts/`에 둔다.
2. 사용자·테넌트가 제공한 자료는 fail-closed로 격리하고 자동 공개하지 않는다.
3. AI 분석은 제안 초안이다. 정답·배점·문항 수·등급컷·점수 분포를 추측하지
   않는다.
4. 교사 작성 텍스트·수식·그림·도형·미주를 우선 보존한다. 자동 분리는 교사가
   승인하기 전 canonical 결과가 아니다.
5. 참고 자료는 정보 커버리지 검증에만 사용하고 최종 디자인·문체·학교/강사
   identity를 복제하지 않는다.
6. 공개 게시와 다운로드 생성은 별도 작업이다. 검수된 정확한 version과 source
   fingerprint를 고정한 뒤 사용자가 명시적으로 게시한다.
